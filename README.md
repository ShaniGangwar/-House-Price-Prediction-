# House Price Prediction

This is a machine learning project that predicts the price of a house.
It uses features such as area, number of bedrooms, and location.

## Tech Used
Python, Pandas, Scikit-learn

## How to Run
pip install -r requirements.txt
python main.py

## Result
The model gives a reasonable estimate of a house's price based on the input features.
